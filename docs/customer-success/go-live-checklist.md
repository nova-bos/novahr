# NovaHR Go-Live Checklist

**Used by:** Customer HR Admin, on the day of the first live payroll.
**Rule:** every box ticked before Publish is clicked.

---

## Data Final Check

- [ ] All joiners for this period captured with complete pay details
- [ ] All leavers terminated with correct end dates and accrued leave payout included
- [ ] Salary changes effective this period applied
- [ ] Overtime hours captured and agreed rates confirmed
- [ ] Bonuses and once-off earnings captured
- [ ] Unpaid leave days captured
- [ ] Garnishees and new recurring deductions captured

## Calculation Review

- [ ] Run summary headcount matches expected headcount
- [ ] Total gross within expected range of last month (differences explained)
- [ ] One payslip per pay grade opened and sanity-checked
- [ ] Every new starter's payslip individually reviewed
- [ ] Every leaver's final payslip individually reviewed (leave payout, pro-rata)
- [ ] PAYE on one sample verified against the SARS calculator
- [ ] UIF lines equal 1% capped at R177.12 (2026/27)

## Compliance and Records

- [ ] Compliance disclaimer acknowledged (first run only)
- [ ] Run approved by an authorised HR Admin (audit-logged)
- [ ] Run report exported and archived to your document store

## Publication

- [ ] Payslips published
- [ ] Test employee (yourself) received the payslip email and PDF opens correctly
- [ ] Employees notified where they will find payslips

## After Pay Day

- [ ] Payments made from your bank match net pay per the report, to the cent
- [ ] EMP201 figures taken from the run report; filing diarised before the 7th
- [ ] UI-19 declaration updated (joiners and leavers)
- [ ] Any employee queries logged and resolved; corrections (if any) scheduled for next run, never silent edits
