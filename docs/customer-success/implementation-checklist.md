# NovaHR Implementation Checklist

**Used by:** NovaHR (customer success) and the customer's HR Admin, jointly.
**Purpose:** single tracking sheet for an implementation from sign-up to go-live. Mirror of the Onboarding Guide in checklist form.

**Customer:** ______________ **Plan:** ______ **Target go-live:** ______ **CS owner:** ______

---

## 1. Commercial and Legal

- [ ] Subscription active; first invoice issued
- [ ] Terms of Service accepted (account owner, in-app record)
- [ ] Data Processing Agreement accepted
- [ ] Welcome email and pack sent
- [ ] Onboarding session booked (Growth/Scale)

## 2. Company Configuration

- [ ] Company profile complete (legal name, address)
- [ ] PAYE reference captured
- [ ] UIF reference captured
- [ ] SDL liability determined and toggle set
- [ ] Pay frequency and pay day set
- [ ] Leave policies configured and checked against employment contracts
- [ ] Departments created
- [ ] Positions created

## 3. Employee Data

- [ ] Source data gathered (Payroll Setup Guide checklist)
- [ ] All active employees captured: ____ of ____
- [ ] Dates of birth verified against IDs
- [ ] Income tax numbers captured
- [ ] Medical aid dependant counts verified
- [ ] Pension percentages verified
- [ ] Travel allowance inclusion rates set (80/20)
- [ ] Banking details verified against bank letters
- [ ] Opening leave balances set at cut-over date

## 4. Users and Access

- [ ] HR Admin(s) active
- [ ] Managers invited and linked to departments
- [ ] Employees invited (self-service)
- [ ] User accounts linked to employee records
- [ ] Role assignments reviewed (least privilege)

## 5. Verification

- [ ] Test payroll run created
- [ ] Parallel comparison against previous payroll: all differences explained
- [ ] Accountant/practitioner sign-off on sample payslip
- [ ] Payslip email delivery tested
- [ ] Compliance disclaimer acknowledged by HR Admin

## 6. Go-Live

- [ ] Period data final (joiners, leavers, once-offs)
- [ ] Run approved and published
- [ ] Run report exported and archived
- [ ] EMP201 deadline diarised (7th)
- [ ] UI-19 process confirmed
- [ ] Go-live confirmed to customer; onboarding closed

## 7. Post-Go-Live (Day 30)

- [ ] 30-day check-in call/email completed
- [ ] Second run completed without parallel support
- [ ] Outstanding issues: ______________________
- [ ] Health score assigned (see Customer Health Check Process)
