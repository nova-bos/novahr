# NovaHR Video Library Plan

**Owner:** Founder
**Tooling:** screen recordings (Screen Studio / Loom / OBS) on the polished demo tenant; talking-head on phone + lapel mic; captions always (most social video is watched muted).
**Order of production** is by sales impact, not category. Scripts kept in this file as they are written.

---

## Standing Conventions

- Demo tenant only; realistic SA data; never real customer data on screen;
- Intro under 5 seconds, no logo stings; end card: novahr.co.za + one CTA;
- Re-record any tutorial invalidated by UI changes (log affected videos in release checklist);
- Naming: `novahr-[category]-[topic]-v[n].mp4`; masters in [Drive folder ●]; published to YouTube (unlisted for support, public for marketing) and embedded in the knowledge base.

## Script Skeleton (all tutorials)

1. **What you will achieve** (one sentence, show the end state first);
2. Steps, narrated while doing, no filler ("simply", "just" banned);
3. **The mistake to avoid** (one per video, from real support tickets);
4. Where to get help (in-app Help, hello@novahr.co.za).
